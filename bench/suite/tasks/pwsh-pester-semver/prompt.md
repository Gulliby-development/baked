`src/SemVer.psm1` is a PowerShell module with two functions to finish:

- `ConvertTo-SemVer -Version <string>` parses a Semantic Versioning 2.0.0 string (`1.4.0`, `2.0.0-rc.1`, `1.0.0-alpha+build.5`, an optional leading `v`) into an object with `Major`, `Minor`, `Patch` (integers), `PreRelease` (an array of the dot-separated identifiers, empty when there are none) and `Build` (a string, empty when there is none). An invalid string (`1.2`, `1.2.3.4`, `01.2.3`, `1.2.3-`, an empty pre-release identifier such as `1.0.0-a..b`) throws an error whose message contains `Invalid version`.
- `Compare-SemVer -Left <string> -Right <string>` returns `-1`, `0` or `1` by SemVer precedence: numeric identifiers compare numerically, alphanumeric ones in ASCII order, a numeric identifier is lower than an alphanumeric one, a version with a pre-release is lower than the same version without, a longer pre-release wins when all shared identifiers are equal, and build metadata is ignored.
