A new desktop screen, settings page or dialog ships with a Playwright spec in `apps/desktop/e2e/` against the mock bridge that walks its main flow; a new section of `src/renderer/router.ts` is swept by `e2e/baked-style.e2e.ts` on its own, and a new dialog joins its `DIALOGS` list. No desktop CSS sets `scrollbar-width` or `scrollbar-color` other than `none`, since Chromium then draws the system scrollbar instead of the one in `base.css`.
