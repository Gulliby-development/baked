No component or hook goes under `src/core/`, which imports neither `react` nor `@opentui/react`. The dev preload `plugins/react-compiler.ts` runs Babel and the React Compiler on every other file under `src/` that a `bun` process loads, and leaves `src/core/` out because it holds 85% of `src/`: compiling it added about 8 s to every test fixture child that imports the workflow core, and 55 s on a loaded macOS runner (#1919). `tests/react-compiler-scope.test.ts` checks both. A UI piece the core needs lives under `src/components`, `src/hooks` or `src/stores` and is passed in.
