A `baked serve` request error that comes from the client's input (`ZodError`, `SyntaxError` from a JSON body, `URIError` from a path segment's percent escape) is mapped to 400 `INVALID_REQUEST` only in `errorOf` (`src/core/api/server.ts`, #2790), never by a try/catch in one route; a route that adds another parser of request input adds its error class there, with a case in the status test of `tests/core-api.test.ts`.
