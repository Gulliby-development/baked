A new session made from another one (`baked session fork`, `forkSavedSession` in `src/core/checkpoints/session-fork.ts`; the API fork through `ChatService.create`) takes the source's conversation, title and project, never its own session fields (`kind`, `worktree`, `archived`, `parentId`), so a fork never becomes a second coordinator, shares a worktree or hides; `tests/session-fork.test.ts` "the fork is a session of its own" fails when one is copied (#2811).
