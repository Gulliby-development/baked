A chat tab's saved token usage (`TabMeta.tokenUsage`) has one meaning on every surface: `prompt` is uncached input, cache reads and writes are apart, and `modelBreakdown` holds the same split per model, which prices the tab. Every surface loads it through `readTabUsage` (`src/core/sessions/token-usage.ts`), which also reads tabs headless or the API saved before this rule; headless and the API add spend through `addTabUsage`, and the TUI's own step accounting (`src/hooks/useChat.ts`) keeps the same split. A new surface or a new source of spend (compaction, a sub-agent) goes through them, with a case in `tests/session-token-usage.test.ts` (#2784).
