The chat's preview panel (#2298) takes its document kinds from `PREVIEW_KINDS` in `src/core/files/preview-kinds.ts` only, which `GET /v1/files/preview` uses too, and finds the documents of a session only in `previewTargets` (`src/core/files/preview-targets.ts`), which the desktop panel, the TUI's `/preview` and `baked preview list` share (#2299). A new previewable kind is added to `PREVIEW_KINDS` with a case in `tests/file-preview.test.ts`; a new tool that writes files joins `WRITE_PATHS` there, and a new artifact tool output joins `previewOf`, each with a case in `apps/desktop/tests/chat-preview.test.ts`. The panel draws HTML only in a sandboxed frame without `allow-same-origin` or scripts; running a page goes through Open.
