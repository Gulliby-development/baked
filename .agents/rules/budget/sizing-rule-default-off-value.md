The few-path share (`sizing.fewPathPrice`) is on by default since #2893 (`fewPathPriceOn` in `src/core/workflows/initiatives/estimate.ts`; `false` turns it off). A sizing rule that graduates from opt-in to default keeps an explicit off value in the policy and in `replayInitiativeStarts`, and the corpus backtest that compares the rule with the old pricing passes that off value, never an absent one (`tests/forecast-replay-corpus-few-paths.test.ts`). A test that pins an old round's prices for another rule replays with the pricing that round ran with (`RECORDED_SIZE_POOLS`, as `RECORDED_PLAN_CHARGE` does).
