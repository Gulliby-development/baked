A prompt input that lists run evidence goes through `evidenceContext` in `src/core/workflows/scheduler.ts`, which bounds the section with `boundEvidence` (`src/core/workflows/evidence-budget.ts`, #2617): a passing check is its status and last line, repeated runs of one check with one output are listed once, and the content stays within `EVIDENCE_BUDGET_CHARS`, failing output and diffs first. Never build an evidence list of your own or raise the budget for one caller; `tests/workflow-scenario-evidence-bound.test.ts` fails when code outside `evidenceContext` numbers evidence handles or an input's `evidence` lists the store's rows.
