The files a released feature's upstream symbols are looked up in come from `upstreamFiles` (`src/core/workflows/initiatives/upstream-symbols.ts`) and nowhere else: a dependency's path that the released feature or any non-dependency also lists (a skeleton owner's stub that another feature fills) is not upstream code, and a path several dependencies list names the one planned last. A new source of upstream files (an accepted run's diff, skeleton stub fates) joins that function with a case in `tests/workflow-scenario-planahead-upstream-symbol.test.ts` (#2192). A phrase that names a helper rather than a member is read in `upstreamSymbolGaps` by its determiner: an indefinite helper ("a public Reader helper") is a gap, a given one (`GIVEN`: "the given", "supplied", "provided", "verbatim") whose file is upstream is that file; a new wording joins `GIVEN` with a case in that test and the gate-matrix upstream symbol cell (#2566).
