A test that runs git against a remote or an auth path (a 401, a missing key) runs it with `GIT_CONFIG_NOSYSTEM=1`, an empty `GIT_CONFIG_GLOBAL` and `-c credential.helper=`, so only the paths the code under test controls answer: the windows-latest system config starts Git Credential Manager on a 401, which outlived a 30 s spawn timeout and held the pipes 20 s more after git was killed ("git command fails cleanly instead of prompting" in `tests/spawn-safety.test.ts`, #2872).
