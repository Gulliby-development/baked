A CI job that only skips on some events (a matrix entry whose steps all check a `scope` output) picks `ubuntu-latest` in `runs-on` when it will skip, for example `runs-on: ${{ needs.scope.outputs.native == 'true' && matrix.runner || 'ubuntu-latest' }}`. Otherwise it waits for a macOS or Windows runner just to echo "Skip". On 2026-11-04 macOS arm64 runners were short, and GitHub cancelled such waiting jobs after 15 minutes, so the merge queue ejected #2908 twice with no failing test (#2915, `.github/workflows/builds.yml`, `.github/workflows/os-tests.yml`). Keep the job's `name:` unchanged, because required checks match on it.
