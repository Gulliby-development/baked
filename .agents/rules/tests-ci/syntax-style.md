A native OpenTUI resource (a `SyntaxStyle`, anything made with a `NativeResourceOwner`) belongs to the renderer that draws it, never to a module: a component takes its code style from `useSyntaxStyle` (`src/hooks/useSyntaxStyle.ts`), which `getSyntaxStyle(renderer.nativeScene)` in `src/core/utils/syntax.ts` keeps once per renderer's resource context. A new native resource is made through the same kind of per-owner lookup, with a case in `tests/tui-syntax-style.test.tsx` that draws it in two renderers (#2404).
