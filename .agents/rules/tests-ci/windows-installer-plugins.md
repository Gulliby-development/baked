The Windows installer (`packaging/windows/BAKED.nsi`) uses no third-party NSIS plugin: the user PATH is edited by the embedded `packaging/windows/user-path.ps1` (read without expanding, written back as the same value kind) and announced with a `SendMessage ... /TIMEOUT=5000` broadcast, because the EnVar plugin hung the installer once and crashed the uninstaller twice in 60 install/uninstall cycles on Windows 11 (#2864). A CI step that runs an installer or uninstaller waits a bounded time, prints the process tree and fails, never waits for the job timeout (4.5 h once).
