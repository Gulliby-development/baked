A test that asserts a process it stopped (or that process's tree) is no longer alive pins the PID with `pinPid` from `tests/helpers/pin-pid.ts` while the process still runs, and releases it after the assertion: Windows hands a dead process's PID to the next new process as soon as no handle to the old one is open, and on a busy runner a stranger under the old PID read as alive in 19 + 8 + 5 queue runs (#2900, #2901, #2849). A child that would exit on its own before the test can pin it waits for a line on its input (`exitOnInput`, ended by `release`). `pinPid` does nothing outside Windows.
