A pull request's own tests run on Windows and macOS before the merge queue, picked by `scripts/pr-targeted-tests.ts` from the files it changes. A test of platform-sensitive code names the module it tests by its import path (or starts its fixture by file name), so the picker finds it; `tests/pr-targeted-tests.test.ts` covers the matching. The shards of each platform split the picked files by measured time (`TEST_FILES` in `scripts/test-shard.ts`), as the queue splits all of them, never one job alone: `tests/pr-targeted-tests.test.ts` and `tests/os-tests-workflow.test.ts` fail when they run in one shard (#2907).
