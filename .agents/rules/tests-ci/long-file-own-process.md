A test file measured at `ALONE_SECONDS` (`scripts/test-shard.ts`) or more on its OS runs in a `bun test` process of its own, after the shard's other files have run together, and its JUnit report is merged with theirs for `slow-tests.ts` and `flaky-ledger.ts`. Do not gather long files back into one process, and do not lower a file's measured weight to keep it in the shared one: on macOS, subprocess tests that ran after the replay corpus's pools file in the same process stalled for 30 s, while the same tests passed alone (#3034). `tests/test-shard.test.ts` fails when the pools file no longer runs alone on macOS.
