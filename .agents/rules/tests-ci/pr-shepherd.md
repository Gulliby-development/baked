A claim on an issue is a comment that says "Claimed" (or an assignee, or an open pull request naming `#N`), and an issue that waits on the owner carries `needs-gulliby`, `deferred`, `idea` or `verification`; a `smoke` issue is a run log unless it is also labelled `bug`, which makes it work. `scripts/pr-shepherd.ts` (`.github/workflows/pr-shepherd.yml`, every 2 h) lists every other open issue as unclaimed, a comment claim with no issue update and no open pull request for `STALE_CLAIM_HOURS` (72) as stale, and every ready pull request outside the merge queue with conflicts, failing or hung checks or no auto-merge as stuck, in one tracking issue the shepherd loop works from; a stale claim is re-routed or taken over, never left to sit. A new skip label or claim wording goes into its `SKIP_LABELS` or `CLAIM`, not into a line's habits.
