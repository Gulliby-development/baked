A host tool that inserts into a file at a place the model names (`place_rows`) takes that place in a form an earlier insert of the same session cannot move: a line the model quotes (`after`, resolved by `anchorLine` in `src/core/tools/place-rows.ts`), with an absolute `line` only for a single call or to pick among equal lines, and its result names where the text went (the line it follows and the list that holds it, `placedWhere`), never only the line numbers, so a wrong place shows in the same turn. R102 tailcut `filters` T002 placed a two-list C++ file in two calls with lines computed before the first insert, and the second list's rows landed in the first (#2956); `tests/workflow-scenario-place-rows-two-lists.test.ts` holds that case.
