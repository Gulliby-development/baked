A layout a host tool gives the lines it writes takes its separator from `ROW_SEPARATOR` (`src/core/tools/place-rows.ts`) as it takes its indentation from `ROW_INDENT`, never from a fixed literal: a row the request ends with `,` or `;` keeps its own, a caller's `separator` replaces it, and otherwise the language's row decides (nothing in Bash, where a bats row is a command; `;` in OCaml; a comma elsewhere, and for a `none(reason)` row). The record is registered in `tests/language-parity.test.ts` with a golden per fixture, so a new language without a row fails; `SEPARATOR_DEFAULT` names the per-language values in the tool's description and the brief's note, and a change to a value adds its case to the `#3060` scenario in `tests/place-rows.test.ts` (#3060).
