A string literal the host writes into a project file (the acceptance rows templates) never holds a character of `LITERAL_ESCAPED` raw: JSON text goes through `jsonText`, and a language's own literal writer escapes those characters with `escapeInvisible` (`src/core/workflows/acceptance-rows-inline.ts`). A new framework's writer gets a case in `tests/workflow-scenario-rows-raw-chars.test.ts`, which also runs the block in the language's own toolchain where the machine has it. The check that a host block is intact compares what it means (`layoutFree`), never its bytes, so an escape that spells the same row is never put back (#1995).
