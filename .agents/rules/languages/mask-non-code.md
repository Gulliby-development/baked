Code that reads a test or source file as code, and not its comments or strings, goes through `maskNonCode` or `stripComments` in `src/core/workflows/quality/code-mask.ts`, whose per-language syntax is the `MASK_SYNTAX` record; a matcher of the case walk never searches raw file text for evidence (#1846). A new literal shape the walk holds gets a case for each of C#, Go, Java, Python and TypeScript in its scenario test. The left side of a before/after pair in a Then (`"0.1.0" -> "0.2.0"`, `from A to B`, `A becomes B`) is the state before the change, not a case; its phrasings are data (`BEFORE_AFTER_PHRASINGS` in `src/core/verification/criteria-cases.ts`), and a new phrasing gets a case per language in `tests/workflow-scenario-case-walk-before-after.test.ts`, which fails when one lacks it (#2000).
