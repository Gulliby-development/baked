Code and tests that pick a Python interpreter use `findPython` or `pythonExecutable` from `src/core/platform/python.ts`, never a bare `Bun.which("python3")`, `commandExists("python")` or a fixed `python`/`python3` name: Windows ships `python.exe` and `python3.exe` App Execution Aliases in `WindowsApps` that, without the Store package, print "Python was not found" and exit 9009, so a machine with python.org Python has a `python3` on PATH that runs no Python (#2992). A program name the run's own checks give (repro runtimes, entry-point launchers) stays as the check names it.
