A toolchain gate that reads what another gate writes (CMake's build, CTest and clang-tidy read the `build/` tree `cmake-configure` writes) states it in `GATE_PREREQUISITES` (`src/core/workflows/gate-prerequisites.ts`) with the marker file the prerequisite writes (no marker when the output must be current, not only present: `ctest` runs `cmake-build` every time, #2565), so `CheckRunner.run` runs the prerequisite first in a worktree without it, never by an order the worker has to know; the gate-matrix prerequisite cell fails when a row names a gate no detector offers (#2526).
