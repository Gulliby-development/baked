A formatter gate a toolchain detector offers (`src/core/workflows/gates.ts`) gets its file-scoped form in `FILE_FORMATTERS` (`src/core/workflows/format-written.ts`, a `LanguageRecord` registered in `tests/language-parity.test.ts`) in the same pull request: check mode and write mode on named files, or `none(reason)` where a file-scoped run cannot be told from the whole unit's, plus its `range` form when the formatter can format a range of lines (or a comment saying it cannot); a range flag that older releases lack names its first release and sets `probe`, so a formatter without it gets no range check (#1907). The format-written check holds the files a task creates whole and the files it edits only on the lines the run changed (#1582) to the project's formatter when no formatter check in the run's checks covers the file (its paths and `cwd`, not only its program), and a host check that holds only some of a task's files sets `fixPaths` so its fixer touches no other file (#1837). A file the task creates whose content the request supplies whole (`suppliesWhole` in `src/core/workflows/supplied-drift.ts`) is never rewritten by a format-written fixer: it gets the advisory `<gate>-supplied` check without a fixer, and `tests/workflow-scenario-format-written-supplied.test.ts` holds that for every `FILE_FORMATTERS` row (#2504). In a file it edits, the changed lines the request supplies (`suppliedLineNumbers`) leave the range through `rangesWithout`, so the format-written range and `supplied_drift` never ask for different bytes of one line; a new `range` row gets its case there automatically (#2596). A formatter whose program may lack the formatter altogether (a Bun before 1.4.4 has no `bun fmt`) sets `available`, so no check is built that would fail every attempt (#1920). A formatter that runs inside an interpreter (an R package under Rscript, a PowerShell module under pwsh) is probed for that package through `packageNeeds` (`src/core/workflows/package-probe.ts`): format-written builds no check without it, and the start smoke refuses a required check whose package is missing with the install command (`missing_package`); a new interpreter or cmdlet gets its entry there and a case in `tests/workflow-scenario-formatter-package.test.ts` (#2817). A formatter that formats text, not files (Invoke-Formatter), runs as a short interpreter script that takes the files after it and writes UTF-8 in the file's own BOM state (`src/core/workflows/ps-format.ts`, as styler runs through `r-tools.ts`), with a live gate-matrix cell skipped without the tool (#2595). A formatter the edit tools detect (`detectJsFormatter` and the other branches of `detectToolchain` in `src/core/tools/project.ts`) also gets its stdin form in `formatProbeCommand` (`src/core/tools/auto-format.ts`), or nothing is formatted after an edit, with a case in `tests/edit-format-toolchains.test.ts`; detection the edit tools and the gates share lives in one helper both import (`ruffSource`, `bunFmtConfigured`).
