A pull request that adds a language to `SUPPORTED_LANGUAGES`, or fills a supported language's `none` rows (a gate detector, test runner, formatter, reviewer), follows the [add-language skill](../../../.agents/skills/add-language/SKILL.md) before it writes code and again before it opens: it lists every layer outside the records that keeps its own language list, and the toolchain bugs earlier languages hit (Windows wrappers, whole-unit analyzers, failure signatures, empty test runs, files a first build writes), each with the test that holds it. One pull request per language, with its fixture goldens, a gate-matrix block and a bench-suite task. A new rake a language pull request finds joins the skill's list.
