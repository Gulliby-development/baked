A block the host writes into a file an agent owns (the inline acceptance rows of `src/core/workflows/acceptance-rows-inline.ts`) keeps the layout a brief sets for that language: in Java and C#, where briefs ask for one top-level type per file, the block is a class nested in the file's own type (`nest` on the template), and in PHP, where PSR-1 keeps one class per file, it is methods of that class. A new inline template for a language with one type per file nests the same way and gets a case in `tests/workflow-scenario-rows-one-type.test.ts`, which also fails when a framework that adds no type starts to (#1804).
