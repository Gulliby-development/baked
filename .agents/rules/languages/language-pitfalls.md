A language's pitfalls note lives in one table read by the reviewer and the implementer: `LANGUAGE_PITFALLS` (`src/core/agents/profiles/language-pitfalls.ts`, a `LanguageRecord` registered in `tests/language-parity.test.ts`), whose `review` clause the language reviewer's instructions are built from and whose `implement` note an implementer step gets (opt-in `languagePitfalls`, shadow otherwise, `pitfall-notes.ts`), never a pitfall written into a profile's text of its own. A new supported language adds its row (or `none(reason)` when the reviewer holds no pitfalls for it); a new reviewer pitfall goes into its language's row, with the implementer note taken from it. `tests/language-pitfalls.test.ts` fails when a language the reviewer runs for lacks a note, when a note holds a code span the reviewer's text does not, or when a note passes `PITFALL_NOTE_MAX` characters, since every implementer step resends it (#2598).
