A dependency manifest reader in `DEPENDENCY_MANIFESTS` (`src/core/workflows/quality/manifests.ts`) states its executable fields (`fields`, extractors in `quality/manifest-fields.ts`): what runs code or chooses where code comes from, which the manifest field check holds to the request (#1793). The type requires the entry; add a cell for the manifest to "manifest executable fields" in `tests/gate-matrix.test.ts` with one executable and one plain change. A file that chooses the toolchain or tool distribution that runs the checks (`go` line, `rust-toolchain`, `global.json` `sdk`, wrapper `distributionUrl`, `requires-python`) counts as an executable field; a toolchain file with no dependencies goes in `TOOLCHAIN_FILES` beside `DEPENDENCY_MANIFESTS` with its own cell (#1963). A lock that records the project's own version goes in `LOCK_FIELDS` (same file) with an extractor that leaves out only the project's own entries (`quality/lock-fields.ts`), a gate-matrix cell, and a row in the auto-approval test of named locks (#1934).
