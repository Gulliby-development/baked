Which files the `glob` tool lists is decided only by `globMatcher` in `src/core/tools/glob.ts` over the vendored `rg --files` listing (hidden and gitignored files left out): a pattern with a slash matches from the base directory, one without at any depth, never the base name alone as `fd --glob` and `find -name` did (#2681).
