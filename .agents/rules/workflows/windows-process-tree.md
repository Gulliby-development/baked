A Windows process the table cannot open is not taken as live until a second snapshot still lists it under the same parent (`readProcessTree` in `src/core/platform/process-table-win32.ts`, #2840): a process that exits between the Toolhelp snapshot and `OpenProcess` cannot be opened either, which read as a live child of a stopped command. A new read of the Windows process table goes through `readProcessTree`, and the "Windows process tree exit race (#2840)" cases in `tests/platform-windows.test.ts` fail without the second snapshot.
