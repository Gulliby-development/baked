A path BAKED writes into a temporary index with `update-index --index-info` (the run branch in `commitRunBranch`, the provisional base in `provisionalBase`, the delivery plan in `prepareDelivery`) is first checked with `inSubmodule` against the base tree's `treeSubmodules` in `src/core/workflows/delivery-git.ts` (#2798). `--index-info` silently replaces a gitlink with a file written inside it, so the commit would drop the submodule. A delivery reports such a path as excluded with the reason `submodule`, and a run branch commit skips it. A new commit path applies the same filter and adds a case to the submodule tests in `tests/workflow-delivery.test.ts` or `tests/workflow-worktree.test.ts`.
