A check of whether a file holds the task's own earlier write reads the task's uncommitted writes in every root through `taskWritesElsewhere` (or `taskEditsInPlace`) in `src/core/workflows/rollback.ts`, never a root filter of its own: one task's attempts can run in the run root and in a batch worker, restart or best-of-N worktree cut from the run root's content (#2585, #2928). A refusal that records a root for recovery decides with `refusalInRunRoot` whether `--accept-workspace` can act on it, and builds its advice with `refusedEditAdvice` in `src/core/workflows/refused-edit.ts`: a task worktree is rebuilt on resume, so its advice is resume or revise. `tests/workflow-scenario-root-split-guard.test.ts` holds the cases.
