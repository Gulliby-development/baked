Host state that outlives a workspace (a file in the BAKED data directory, such as `first-byte-history.json` of the adaptive first-response deadline) is written only by a run whose policy turns it on, read back before each write so other processes' entries are kept, written through a temporary file and a rename, and bounded per key. The workspace's own record comes first, and the shared state only fills in where the workspace has too little (#1880).
