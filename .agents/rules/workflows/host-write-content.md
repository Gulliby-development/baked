Whether the host writes a task's files from the plan's `content` instead of starting an implementer is decided only by `hostWritten` in `src/core/workflows/task-graph.ts`, never by a caller testing `w.content !== undefined`: content that is empty on every write of a task, unless every write is a marker file, counts as absent (`emptyHostContent`, #2610), is reported to the planner by `hostContentProblems` and taken out of the stored graph by `withoutEmptyHostContent` in `planGraph`. A new kind of legitimately empty file is a row of `EMPTY_MARKER` there.
