The property-test mode of a run is decided by `propertyTestsOf` (`src/core/workflows/quality/properties.ts`), reached in the scheduler only through `propertyMode`, which gives it the request, the policy and the repository's own tests (`quality/property-repository.json`). A host default that adds a test construct (property loops, generated inputs) gives way to an existing repository that has none, unless the request asks for it. A language that gains a property library joins `PROPERTY_LIBRARIES` with a case in `tests/property-tests-brownfield.test.ts`.
