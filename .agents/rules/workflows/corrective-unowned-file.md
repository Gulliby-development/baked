A host decision a person can take for a blocked corrective's unowned file (`corrective_unowned_file`, #2133/#2155) is a remedy kind in `HOST_REMEDIES` (`src/core/workflows/remedies-model.ts`) mapped to its decision in `REMEDY_DECISION` (`src/core/workflows/corrective-scope.ts`); a new one adds both, its TUI key, CLI `--remedy` value and desktop button, and a scenario case in `tests/workflow-scenario-corrective-unowned-file.test.ts` in the same change. A new host decision of `unownedRule` (as `amend` for a lone test file of a closed upstream feature, #2485) adds its case to `unownedSummary` (exhaustive over `UnownedDecision`, so the compiler names a missing one), its place in `hostDecision`'s order, the remedy that answers it in `remedyCovers`, its inputs to `UnownedPath` (passed on by `replayCorrectiveScopes`), its own stop reason in `stop-reasons.ts` (shadow, the park or block it replaces staying the enforced answer) and an enforced, a shadow and a still-parks case to `tests/workflow-scenario-corrective-unowned-file.test.ts` on two stacks, which fails when the decision acts in shadow or is never recorded.
