A failed Git command is reported through `gitFailure` in `src/core/workflows/delivery-git.ts` (the command, its exit code with the Windows status in hex or its signal, and stderr or "printed nothing"), never by interpolating stderr alone, which is empty when the process ended before Git ran (#3041). A read-only Git command whose failure would block a run goes through `gitRead`, which runs it once more after a silent failure; a command that writes (commit, worktree add, push, update-ref) never does. `tests/git-read-retry.test.ts` holds the cases.
