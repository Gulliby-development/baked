A test check that fails only because the test binary has no `main` yet (the linker lines in `NO_ENTRY_POINT_LINES`, `src/core/verification/convergence.ts`) ran no test, so `testsNotBuilt` treats it like `noTestsCollected` while the plan's test files are not on disk: the reported-defect path records `no_tests` and charges nothing to the source (#2997). A new linker's form of a missing entry point adds its line to `NO_ENTRY_POINT_LINES` and its case to `tests/workflow-scenario-test-link-no-main.test.ts`; a missing `main` the output charges to a planned test file stays a failure.
