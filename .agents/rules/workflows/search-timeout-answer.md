A search tool whose process its timeout stopped (`searchOutcome` in `src/core/tools/grep.ts` returns `timed-out`) answers with `timedOutResult`: a failed result saying the search stopped, with any hits it printed before, never "No matches found." and never a fallback search that could answer that. A new search tool that runs ripgrep, grep or a similar command uses the same two helpers and the `searchLimits` timeout, and `tests/grep-timeout.test.ts` gets a case for it (#3037: a Windows search stopped at 10 s told the model a directory with matches had none).
