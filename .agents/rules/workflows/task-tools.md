Which host tools a task's implementer is offered, by the task's shape (planned or a correction, its writes, its findings), is decided only by `TASK_TOOLS` and `toolsOfferedTo` in `src/core/workflows/task-tools.ts` (#2643): the executor's grant and the scheduler's repro check read it, the planner, quick planner, spec author and analysis instructions state it through `plannedTaskToolsRule`, and `taskToolProblems` refuses a plan whose task text names a tool that task will not get. A new host tool whose grant depends on the task adds its row there, never an inline condition in `agent-executor.ts`.
