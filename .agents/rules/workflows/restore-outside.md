A host process that puts files back or removes them in a run's root during an attempt without an effect row (a fixer's `restoreOutside`, the unjournaled-change put-back before a scope check, a refused probe's leftover change) records what it did with the attempt: `recordPutBack` in `src/core/workflows/fixer-scope.ts` (`attempts/ATTEMPT/put-back-ID.json`), the `reverted-outside` diagnostic, or the probe record's `changed`, so a file that vanishes names its source (#2609). A new such put-back records the same way, and never removes a file the task itself writes. `tests/workflow-check-fix.test.ts` fails when `apply_fix` removes a task file created during its run or records nothing; `tests/workflow-scenario-vanished-run-file.test.ts` fails when the resume refusal and `--accept-workspace` disagree on a refused file.
