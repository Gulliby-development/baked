A model tool that searches or lists files (`grep`, `bake_grep`, `glob`, `bake_find`) refuses a search path that is itself forbidden (`isForbidden`, `src/core/security/forbidden.ts`) and prints the file name on every hit line (`rg --with-filename`, `grep -H`), so its per-line forbidden filter sees every path: ripgrep prints bare `N:text` for a single-file search, and `grep(path: ".env")` returned the secret lines (#2670). A new search tool adds its single-file case to `tests/grep-forbidden.test.ts`.
