A reader that needs the initiative of a run a person decided on or resumed goes through `InitiativeService.ofRun`, which finds a feature run in `initiative_runs` and a decompose run by `initiatives.decompose_run_id` (`decompositionOfRun`); it never queries `initiativeOfRun` alone, which holds only feature runs (#3046). Every surface that continues an idle initiative after a run (headless `finish`, the TUI worker, `baked serve`'s `continueInitiativeOf`) covers the decompose run too, with a scenario in `tests/workflow-scenario-initiative-drive-hint.test.ts`.
