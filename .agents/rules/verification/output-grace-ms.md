A command BAKED runs whose result waits for its output (a check, a chat shell command, a hook, a Git read) stops waiting `OUTPUT_GRACE_MS` after the command exited: a `Bun.spawn` read goes through `processOutput` and a `node:child_process` child that resolves on `close` through `onOutputHeld` (both in `src/core/spawn.ts`), because a process holding the pipes keeps `close` from firing, and on Windows a timeout kill cannot reach it once its parent is gone (#1029, #2657). A new runner of commands gets a case in `tests/process-output-holders.test.ts`.
