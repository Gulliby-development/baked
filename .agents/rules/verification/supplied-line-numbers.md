Which lines of a delivered code file the request gives verbatim is decided only by `suppliedLineNumbers` in `src/core/workflows/supplied-drift.ts`, on `suppliedBlocks` (#2489). `changedFiles` in `scheduler.ts` hands them to every quality gate as `ChangedFile.supplied`, and a match on them is a note recorded with `supplied: true`: in the rule pack (built-in and ast-grep), in Semgrep, and in the duplication ratchet (by span). A new quality gate that reads changed files takes `supplied` the same way, with a case in `tests/workflow-scenario-rules-supplied-verbatim.test.ts`, never its own reading of the request.
