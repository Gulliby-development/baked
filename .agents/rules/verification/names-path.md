A host decision that asks whether a text (a worker's account, an unresolved item, a criterion) names a planned file goes through `namesPath` in `src/core/workflows/task-graph.ts`, and one over a check's output through `pathsInOutput` or `failingFilesInOutput` in `src/core/verification/convergence.ts`, never `text.includes(path)`: a bare substring makes `test_wordcount.py` name `wordcount.py` and `src/app.tsx` name `src/app.ts`, which dropped a task's own unresolved failure and made a blocked task wait for an unrelated one (#2672).
