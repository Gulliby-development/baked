Every reader of a Markdown table row in a spec (the case walk's `tableRows` in `src/core/verification/criteria-cases.ts`, `cellsOf` in `src/core/workflows/acceptance-rows.ts`, and any new one) takes its cells from `tableCells` in `src/core/specs/table-cells.ts`, which splits only at a `|` outside a backtick code span and a double-quoted string and not escaped as `\|`; a row that does not split to its header's width is skipped, never demanded. `tests/table-cells.test.ts` fails when a file in `src/core` calls `.split("|")` outside that module and its explicit list of non-table uses (a new non-table use joins the list with its reason), and a new table literal shape gets a case per language in `tests/workflow-scenario-casewalk-pipe.test.ts` (#2044). A rows cell is parsed through `parseCell` (raw control characters in a string escaped, a code span matched across U+2028/U+2029); a new accepted cell shape adds a case to the #2097 block of `tests/acceptance-rows.test.ts`, and a table the reader refuses is reported through `unreadTables`, never dropped silently.
