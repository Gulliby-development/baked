A host step that runs a command a spec or document quotes (documented examples, `run_repro`, the case walk's source probe) runs it through `entryPointCommand` in a copy of the workspace (`copyWorkspace` in `src/core/verification/doc-examples.ts`), never in the run root, and treats a command that cannot say (not the project's program, not built, an input nobody supplies, a timeout) as no evidence. A probe that finds source code disagreeing with a criterion routes the difference to the task that wrote the source, never to the test task's own correction (#1836). The copy is removed with `removeScratch` (`src/core/verification/repro.ts`), never a bare `rmSync`: on Windows a program stopped at the timeout holds the directory for a moment, and the removal error must not replace the result.
