The documented-example runner (`src/core/verification/doc-examples.ts`) runs an example only on what a reader would have: the workspace plus the files the document tells them to save (`extractFixtures`), and reports a difference that comes from an input nobody supplies as `not_run`, never as a mismatch. A new README shape (an example form, a way to introduce a file) is read in `extractExamples` or `extractFixtures` and gets a case in `tests/workflow-scenario-doc-example-fixtures.test.ts`, whose per-toolchain rows keep it language-agnostic (#1849). A toolchain command that builds before it runs (`swift run`, `dotnet run`) reuses the checks' build only through `EXAMPLE_BUILD` (`src/core/verification/example-build.ts`, a `LanguageRecord` registered in `tests/language-parity.test.ts`, golden in each fixture's `exampleBuild`): its build directories linked into the copy and its no-build flags, or `none(reason)`; a new toolchain adds its row with a case in `tests/workflow-scenario-doc-example-compiled.test.ts`, and a command that timed out once is not run again in the same review (#2505).
