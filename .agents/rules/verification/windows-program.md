A Windows batch script (`.bat`, `.cmd`) is started by its absolute path, never its bare name: `windowsProgram` in `src/core/workflows/process-scope.ts` resolves a bare name on the launch's PATH before `windowsBatchInvocation` (#2432), and every launcher that builds a `cmd.exe /c` line resolves first (`ProcessScope.execute`, sandboxed or not, which every check, fixer, repro, probe and example reaches; `lspLaunch`; the sandbox launcher's `resolveExecutable`). cmd.exe expands `%~dp0` of a quoted bare name to the cwd, and the tools find their own files from it (R77 sbt.bat, Gradle, Maven, npm shims, Composer, LuaRocks wrappers). A new launcher adds its case to the Windows batch cells of `tests/gate-matrix.test.ts`.
