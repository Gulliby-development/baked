A check that reads a missing build output after its build prerequisite passed is a stale build tree, not a code failure: the prerequisite's `staleOutput` row in `GATE_PREREQUISITES` (`src/core/workflows/gate-prerequisites.ts`) names the check's missing-output line and how the prerequisite rebuilds clean, and `CheckRunner.run` rebuilds once, reruns the check, records `stale-build/`, and returns `environment_broken` when the output is still missing (#3054). A new build-and-run gate pair whose tool can record a step done without its output (MSBuild, Ninja, Make with an interrupted link) adds its `staleOutput` to the row with a case in `tests/workflow-scenario-gate-prerequisite.test.ts`; the line must name only the check's own missing-output message, so a failing test never triggers a rebuild.
