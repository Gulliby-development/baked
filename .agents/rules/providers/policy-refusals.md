A provider adapter names the words its provider uses to refuse a request under its usage policy in `POLICY_REFUSALS` (`src/core/llm/policy-refusal.ts`), or `{ none: "why" }`, in the same pull request; `tests/policy-refusal.test.ts` requires an entry for every adapter. The scheduler recognises refusals only through `policyRefusal`, so a refused request is never filed as a lost worker or an outage (#1895).
