A provider adapter that reads a child process's output as JSON lines reads it through `jsonLines` or `onJsonLines` (`src/core/llm/providers/json-lines.ts`), never `node:readline`, which also ends a line at U+2028 and U+2029 inside a JSON string, and records a line that does not parse with `UnparsedLines` instead of dropping it. `tests/provider-json-lines.test.ts` fails on a `node:readline` import under `src/core/llm/providers/`, and a new reader adds its case there (#1956).
