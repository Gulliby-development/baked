A default-on model route (one that applies with no configuration, as `specifyOnSonnet` does in `specifySonnetRoute`, `src/core/llm/model-routing.ts`) returns nothing when `RoutingInputs.strict` is set, because `--model-strict` drops the configuration (`strictRoutingConfig`) and so cannot turn such a route off through it. Every caller that builds a strict run's record passes `strict` to `routingRecord` (the start in `src/core/workflows/start.ts` and `rerouteRecord`). A new default-on route adds its strict case to `tests/model-routing.test.ts` and `tests/workflow-model-shadow.test.ts`, which fail when a strict run still takes it (#2217). A check a strict run's start reads from `strictRoutingConfig` (independence among them) reads the same strict config on reroute (`planReroute`), and `tests/workflow-reroute.test.ts` holds its strict case (#2230).
