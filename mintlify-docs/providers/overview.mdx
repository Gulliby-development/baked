---
title: "Providers"
description: "Supported model connections"
---

BAKED supports five connections. Select a connection and model with Ctrl+L or /models.

| Connection | Provider ID | Authentication |
|---|---|---|
| Claude | anthropic | ANTHROPIC_API_KEY |
| OpenAI API | openai | OPENAI_API_KEY |
| OpenAI Codex | codex | Account login via /codex login |
| GitHub Copilot | copilot | GitHub sign-in in the model selector |
| GitHub Models | github-models | GITHUB_MODELS_API_KEY |

Use /keys to manage API keys. Keys are stored separately from project configuration.
Use /provider-settings for Claude, OpenAI, and shared GitHub reasoning options.

Headless discovery:

```sh
baked --list-providers
baked --list-models openai
```
