BAKED combines a terminal interface, a headless CLI, and a codebase graph. It uses LLM providers to plan work and tools to read, edit, and check code.

## Start

Use Bun 1.3.13 or newer from the repository root:

```sh
bun install
bun run dev
```

Configure a provider through `/keys` and choose a model with `Ctrl+L`. See [installation](/installation), [quickstart](/quickstart), and [providers](/providers/overview).

## How it works

- [Architecture](/concepts/architecture): agent execution, shared state, and analysis backends.
- [Repository graph](/concepts/repo-map): symbols, imports, and context ranking.
- [Code intelligence](/concepts/intelligence): LSP, syntax trees, and fallback analysis.
- [Prompt assembly](/context/prompt-system) and [compaction](/context/compaction): model context management.
- [Memory](/tools/memory), [sessions](/tools/sessions), and [checkpoints](/tools/checkpoints): persistent state and rollback.
