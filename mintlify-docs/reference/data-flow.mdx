## Local data

Global settings are stored under `~/.baked/`; project settings and databases are stored under `<project>/.baked/`. Sessions are saved as JSONL. Memory and the repository graph use SQLite. See [configuration](/reference/configuration), [sessions](/tools/sessions), and [memory](/tools/memory).

Provider credentials are handled by `src/core/secrets.ts` and platform keychain support. Keep credentials out of source files and committed configuration.

## Network requests

The selected model provider receives the assembled model context, including conversation history, tool results, and code read during the task. Search and page-fetch tools contact their configured services. Installing optional tools or fetching model lists can also use the network.

Session-start telemetry is implemented in `src/core/telemetry.ts`; its fields and opt-out settings are documented in [telemetry](/reference/telemetry).

## File access


`src/core/security/outside-cwd.ts` handles access outside the project directory. Tool approval wiring lives in `src/core/tools/index.ts`. When extending tools, preserve these checks at the entry point and filter returned data where required.
